# Отдельная EXE-версия

`source` содержит копию Python-приложения на момент сборки. В этой копии
пути настроек адаптированы для запуска EXE, добавлена автономная проверка.

Готовая программа: `release/Task_Migrator.exe`. Для переноса на другой
компьютер скопируйте всю папку `release`. Python там не требуется.
Инструкции по настройке находятся в `release/README.txt`.

Повторная сборка из PowerShell: `./build.ps1`.
Скрипт использует Python из `../env` с зависимостями `requirements.txt`.
При установке браузера может потребоваться интернет.

Проверка: запустите EXE с аргументом `--self-test`. Она проверяет создание
окна и запуск Chromium на локальной HTML-странице без обращения к Jira.
