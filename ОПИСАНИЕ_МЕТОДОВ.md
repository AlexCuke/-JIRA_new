# Справочник функций и методов программы

Составлен по текущим Python-исходникам. Содержит именованные функции, методы классов и вложенные обработчики, включая тесты. Это справочник реализованного кода, а не гарантия доступности операций на внешних серверах.

## Область описания

Основная программа запускается через `main.py` / `migration_gui.py`. Ниже также перечислены вспомогательные и самостоятельные скрипты корня проекта. Сторонние библиотеки, лямбда-выражения и JavaScript внутри строк не являются отдельными Python-методами и не перечисляются как методы. Подпроекты Java и recovered-angular не входят в эту Python-программу.

`standalone-exe/source` содержит копию исходников для будущей сборки. Общие методы описаны один раз. Варианты кода перечислены в конце. EXE в рамках подготовки документа не обновлялся.

## Основные сценарии и запись данных

| Сценарий | Главные методы | Что меняется |
|---|---|---|
| Миграция новой задачи | `MigrationGUI.execute_migration_process`, `create_issue` | Заполняется целевая форма; создание завершается вручную |
| Синхронизация полей существующих задач | `start_sync`, `sync_pair` | Автоматически сохраняется целевая форма Jira/Redmine |
| Синхронизация статусов | `sync_status_pair` | Выполняется прямой доступный переход Jira или сохранение статуса Redmine |
| Ручная смена статуса Jira | `JiraDestPage.set_issue_status` | Для закрытия может выполняться цепочка переходов |
| Смена исполнителя | `set_existing_issue_assignee` | Сохраняется исполнитель существующей Jira-задачи |
| Экспорт и обновление таблицы | `append_issue_rows`, `update_issue_statuses` | Записываются строки или отдельные колонки Google Таблицы |
| Даты релизов | `sync_release_dates` | Записываются даты в колонку «Срок» по колонке «Версия» |

Для новых операций синхронизации пар и дат исключаются статусы строк таблицы «Закрыт», «В релиз», «Пилот». Более старый метод `get_issue_keys_to_sync` имеет свой набор исключений: смотрите его исходный код. Метод синхронизации статусов читает фактический статус глобальной Jira, а не копирует статус из ячейки.

Отсутствие аннотации результата не означает отсутствие возвращаемого значения. Ссылка ведёт на определение в исходнике.
